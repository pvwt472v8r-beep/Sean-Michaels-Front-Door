# Sean-Michaels-Front-Door
Landing Page for Sean Michael (Real Estate Broker)

## Contact form

The inquiry form posts to FormSubmit for delivery to Sean-Michael's email. It uses native browser validation, FormSubmit's CAPTCHA and confirmation page, and a honeypot for spam prevention. Visitors should not send sensitive personal information through the form.

After deployment, submit a test inquiry from the live site. Sean-Michael must open the activation email from FormSubmit and confirm the address before delivery is enabled; check the spam folder if it does not arrive. Then submit another test and confirm receipt and reply-to behavior. Changing the recipient address requires reactivation. Do not claim the form is receiving inquiries until this test succeeds.
